HGL/z is a single platform as code, released under [HGL](/docs/hgl/). HGL is the license. Z is the single branch of code that every contribution merges into, the codename for our worldwide digital civilization. Together, HGL/z is one project that solves our problems, owned by everyone who builds it.

HGL/z is not one more project among many. It is the stem project. Every other branch forks from it, and every useful fork merges back into it. Building the same thing twice wastes time, so HGL/z does not duplicate what already exists. It extends it. When you need a new function, you add the next code block to HGL/z instead of starting a new project. Each contributor invests a little and gains everything already built.

HGL/z does not have to be a single git repository to be one thing. Many repositories can work together as one when they speak the same words: the same interface and the same protocol. It does not even have to be one protocol. Each relation only needs a protocol that both parties agree to use. Where two repositories agree on how to talk, they are part of the same whole, wherever their code lives.

HGL keeps it whole. Anyone may copy and modify HGL/z, but once you distribute it, the whole source goes to every user, free, under HGL, with no extra restriction. No fork can close what it has to hand over, so every contribution stays in the same branch. Like any protocol, HGL/z is something you build on top of, not something you modify to take control.

BTC protects HGL/z. I build HGL/z code and receive BTC in exchange, which secures my time to build more of it. BTC supplies the energy, HGL/z consumes it, and the work returns to the network without compromising the sovereignty, privacy or security of the client. BTC knows its client without considering non-BTC, and HGL/z knows its server without considering non-HGL/z.

Do you need wealth? Contribute to HGL/z. Do you need code? Use HGL/z, and develop what you use. Do HGL/z and/or BTC. Your choice.
