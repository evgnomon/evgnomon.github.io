# Getting Started

```
sudo apt get install hugo # or equivalent
cd the repo
git submodule update --init
hugo serve
```

Images are generated using a custom prompt:
> rendered as a classic, detailed graphite pencil sketch on aged, light-cream paper. The entire composition is built on intricate, fine-line hatching and cross-hatching to define textures, depth, and shadow. Every element has clear, crisp linework. Use soft, feathery pencil-shading for organic details like skin, leaves, water, and fabric, and precise, clean, geometric lines for technical objects like solar panels, machinery, and charts. The background is composed of soft, diffused graphite dust, giving way to subtle, rhythmic patterns, faint swirling lines, or stylized light-burst motifs. The overall image must maintain a warm, sepia-toned, monochrome feel and the distinct tactile texture of historical hand-drawn pencil work, with high clarity and a hand-crafted quality.
